Fix some cells by hand, and watch the best possible flow react

Each cell (i, j) is the flow on the edge row i → column j. Use − and + on a cell to fix it at a value of your choice (it turns orange). The page then finds the largest flow it can still push with the cells you have not fixed, so every other edge may change. A grid exists only when the flow reaches ΣR = ΣC.

The grid = flows on the middle edges

Orange cells are fixed by you; ✕ releases one. White cells are chosen by the max-flow search. − and + stop at the value that would overflow K, the row's R or the column's C.

The flow network

S → row i, capacity R[i] row → column, capacity K fixed by you column j → T, capacity C[j] labels: flow / capacity · line width = flow
How the page computes the flow

Fixed cells use up part of their row's R and their column's C. The page subtracts them, then runs Edmonds–Karp (shortest augmenting paths) on the remaining network: S → row (what is left of R), row → column for every unfixed cell (capacity K), column → T (what is left of C). The total shown is your fixed flow plus that maximum. If the total is below ΣR, the rows or columns marked "short" cannot be filled, whatever the free cells do.
